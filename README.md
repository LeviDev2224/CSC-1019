## 🚀 Projects

### 🔑 Password Project (`/Password_Project`)
**Class Coursework**
* Core assignment focusing on security fundamentals, password validation, dictionary checking against common passwords, and file logging.
* **Files:**
  * `Main.py`: Interactive script for verifying password strength and criteria.
  * `common_passwords.txt`: Reference dictionary for password validation.
  * `password_log.txt`: Log file tracking validation outputs.

### 🃏 Project JackGPT (`/Project_JackGPT`)
**Independent Side Project**
* An informal, entertaining side project created concurrently with a friend. Originated as a branch of the initial password assignment and expanded into a fun, interactive application separate from standard coursework.
* **Files:**
  * `Main.py`: Application logic and user interaction handlers.
  * `leaderboard.json`: Persistent score and leaderboard data tracking.

## 🛠️ Getting Started

### Prerequisites
* **Python 3.10+**

### Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LeviDev2224/CSC-1019.git
   cd CSC-1019
   ```

2. **Run the Password Project:**
   ```bash
   python Password_Project/Main.py
   ```

3. **Run Project JackGPT:**
   ```bash
   python Project_JackGPT/Main.py
   ```
